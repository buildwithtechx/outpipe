Install the framework-neutral client:

```sh
npm install @outpipe/sdk
```

The SDK provides API operations, relay connection lifecycle, reconnect
handling, and the shared protocol types. It uses the platform `fetch` API, so
it does not add Axios or another HTTP stack to applications.

Keep API keys in server-side environment variables. For browser use, request
a short-lived token from your application backend and construct the client
with that token.

## Relay connection

```ts
import { RelayConnection } from '@outpipe/sdk';

const connection = new RelayConnection({
  relayUrl: process.env.OUTPIPE_RELAY_URL!,
  agentToken: process.env.OUTPIPE_AGENT_TOKEN!,
  reconnect: true,
});

await connection.connect();
const tunnel = await connection.openTunnel({
  local_port: 3000,
  protocol: 'http',
  password: process.env.TUNNEL_PASSWORD,
});

console.log(tunnel.public_url);
```

Call `closeTunnel` before `close` when the process owns a tunnel. The SDK
emits connection, authentication, error, and tunnel lifecycle events for
application logs and status indicators.
