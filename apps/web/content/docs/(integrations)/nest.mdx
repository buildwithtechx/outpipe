---
title: NestJS integration
description: Start and stop a tunnel with NestJS module lifecycle hooks.
icon: SiNestjs
---

Install the adapter:

```sh
npm install @outpipe/nest
```

Register the module once:

```ts
import { OutpipeModule } from '@outpipe/nest';

@Module({
  imports: [
    OutpipeModule.forRoot({
      relayUrl: process.env.OUTPIPE_RELAY_URL!,
      agentToken: process.env.OUTPIPE_AGENT_TOKEN!,
      localPort: 3000,
      autoStart: true,
      password: process.env.TUNNEL_PASSWORD,
    }),
  ],
})
export class AppModule {}
```

The service uses `OnModuleInit` and `OnModuleDestroy`, so application startup
and shutdown own the relay lifecycle. Inject the service when you need the
current public URL or explicit start/stop control.
