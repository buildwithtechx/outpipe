---
title: CI/CD integration
description: Open secure preview tunnels from automated pipelines.
icon: Workflow
---

The CLI is designed to run on a workstation, CI runner, or preview job. It
does not require interactive browser login when an agent token is supplied.

Store the token as a CI secret and pass it through the environment:

```yaml
steps:
  - name: Start preview tunnel
    env:
      OUTPIPE_AGENT_TOKEN: ${{ secrets.OUTPIPE_AGENT_TOKEN }}
      OUTPIPE_PASSWORD: ${{ secrets.TUNNEL_PASSWORD }}
    run: |
      outpipe http --port 3000 &
```

For a private installation, set `OUTPIPE_API_URL` and
`OUTPIPE_RELAY_URL`. The `--agent-token` flag can override the
environment value for a single command.

Use `--tunnel-id` to reconnect a managed tunnel while preserving its public
identity:

```sh
OUTPIPE_PASSWORD="$TUNNEL_PASSWORD" outpipe open --tunnel-id "$TUNNEL_ID" --port 3000
```

Management commands such as `list`, `inspect`, and `revoke` use
`OUTPIPE_API_KEY`.
