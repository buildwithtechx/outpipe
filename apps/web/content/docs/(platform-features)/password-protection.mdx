---
title: Password protection
description: Restrict HTTP tunnel access with Basic Authentication.
icon: ShieldCheck
---

Protect an HTTP or HTTPS tunnel with the CLI:

```sh
outpipe http --port 3000 --password "$TUNNEL_PASSWORD"
```

The relay returns `401 Unauthorized` and a `WWW-Authenticate` challenge when
the request has no valid credentials. The username is not used.

Programmatic clients can send credentials with `curl`:

```sh
curl -u :"$TUNNEL_PASSWORD" https://your-subdomain.outpipe.app/health
```

Passwords are hashed with Argon2id and are never stored in the request logs or
usage analytics. Use a secret manager in CI and do not place passwords directly
in committed configuration files.
