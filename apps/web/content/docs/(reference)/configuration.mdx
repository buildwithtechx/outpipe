Outpipe reads configuration directly from environment variables. All variables are prefixed with `OUTPIPE_`.

## Shared Service Configuration

| Variable | Default | Applies to | Description |
| :--- | :--- | :--- | :--- |
| `OUTPIPE_DATABASE_URL` | `postgres://...` | API, Cron | PostgreSQL connection DSN. |
| `OUTPIPE_DATABASE_MAX_CONNS` | `25` | API, Cron | Maximum connection pool size. |
| `OUTPIPE_REDIS_HOST` | `localhost` | All services | Redis host for affinity and pub/sub. |
| `OUTPIPE_REDIS_PORT` | `6379` | All services | Redis port. |
| `OUTPIPE_INTERNAL_API_URL` | `http://127.0.0.1:9090` | Relay, Cron, Checks | Loopback address for private control-plane RPC. |
| `OUTPIPE_INTERNAL_API_SECRET` | *(required)* | API, Relay, Cron | Shared secret for internal API & edge JWT verification. |

## Control Plane API (`cmd/server`)

| Variable | Default | Description |
| :--- | :--- | :--- |
| `OUTPIPE_PORT` | `8080` | Public HTTP/REST API listen port. |
| `OUTPIPE_PUBLIC_API_URL` | `http://localhost:8080` | Externally reachable API base URL. |
| `OUTPIPE_DASHBOARD_URL` | `http://localhost:3000` | Frontend web dashboard URL for OAuth redirects. |
| `OUTPIPE_ALLOWED_ORIGINS` | `http://localhost:3000` | Allowed CORS origins. |
| `OUTPIPE_AUTH_ENCRYPTION_KEY` | *(required)* | 16, 24, or 32-byte AES key for state encryption. |
| `OUTPIPE_AUTH_COOKIE_NAME` | `outpipe_session` | Name of the session cookie. |
| `OUTPIPE_AUTH_COOKIE_SECURE` | `false` | Set to `true` when terminating with HTTPS. |
| `OUTPIPE_GITHUB_CLIENT_ID` / `_SECRET` | *(optional)* | GitHub OAuth application credentials. |
| `OUTPIPE_GOOGLE_CLIENT_ID` / `_SECRET` | *(optional)* | Google OAuth application credentials. |
| `OUTPIPE_ACME_EMAIL` | *(optional)* | Let's Encrypt email for automated SSL provisioning. |

## Relay Data Plane (`cmd/tunnel`)

| Variable | Default | Description |
| :--- | :--- | :--- |
| `OUTPIPE_PORT` | `8081` | Public WebSocket connection and HTTP proxy port. |
| `OUTPIPE_TUNNEL_DOMAIN` | `outpipe.app` | Base tunnel wildcard domain (e.g. `*.outpipe.app`). |
| `OUTPIPE_TUNNEL_MAX_CONNECTIONS` | `1000` | Maximum concurrent agent sessions per relay. |
| `OUTPIPE_TUNNEL_HEARTBEAT_INTERVAL`| `20s` | Heartbeat keep-alive interval. |
| `OUTPIPE_TUNNEL_READ_TIMEOUT` | `90s` | Timeout for inactive/stale connections. |
| `OUTPIPE_REQUIRE_TLS` | `false` | Enable direct TLS termination on the relay. |

## CLI Client (`cmd/cli`)

| Variable | Default | Description |
| :--- | :--- | :--- |
| `OUTPIPE_API_URL` | `http://localhost:8080` | Control plane API endpoint. |
| `OUTPIPE_RELAY_URL` | `ws://localhost:8081` | Relay WebSocket endpoint (`wss://` in production). |
| `OUTPIPE_API_KEY` | *(optional)* | `opk_live_...` API key for non-interactive environments. |
| `OUTPIPE_AGENT_TOKEN` | *(optional)* | Ephemeral tunnel session token. |
